# Feature: LAN Shared Real-Time Code Clipboard

## Objective
Implement a lightweight real-time code-oriented shared clipboard web application running in a Docker container on the local server `192.168.100.22:3000`, allowing instant synchronization between laptop and desktop with syntax highlighting and clipboard actions.

## Tasks
- [x] Task 1: Create local application structure (Node.js + ws server, CodeMirror web client, Docker setup)
- [ ] Task 2: Validate local build and server execution
- [ ] Task 3: Transfer project files to Debian server `192.168.100.22` via SSH/SFTP
- [ ] Task 4: Build and run Docker container on the server, and verify end-to-end connectivity
